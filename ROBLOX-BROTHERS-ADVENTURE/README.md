# Roblox Brothers Adventure — 2 พี่น้องตะลุยโลกเกม

ซีรีส์ Roblox-style adventure สำหรับนำเข้า PRO V6.8 P&P Movie Studio ที่ STEP6 โดยใช้เด็กสองคนจากภาพอ้างอิงเป็นแรงบันดาลใจด้าน visual เท่านั้น และออกแบบเป็น stylized game avatars ที่ไม่ระบุตัวตนจริง

## Production Standard

- 10 EP / 1 ด่านต่อ 1 EP / จบในตอน
- 10 scenes ต่อ EP
- 8 วินาทีต่อ scene
- ความยาวประมาณ 80 วินาทีต่อ EP
- แนวตั้ง 9:16
- ไม่มี long dialogue
- ไม่มี dialogue และไม่มี narrator ใน scene script
- เน้น music + ambience + SFX + visual storytelling
- โทนสดใส ผจญภัย ครอบครัว ไม่ dark/horror
- Roblox-style เท่านั้น: ไม่มี official logo, ไม่มี copied UI, ไม่มี copied branded map หรือ asset

## Character Continuity

ดู `CHARACTER_SHEETS.json`

- **MAX / แม็กซ์** — พี่ชาย ตัวสูงกว่า ชุด cream + light green, ใจกล้า ช่วยน้อง
- **MINI / มินิ** — น้องชาย ตัวเล็กกว่า ชุด white + blue, ช่างสังเกต แก้ปริศนาเก่ง

ทั้งสองเป็น stylized game avatars อ้างอิงภาพผู้ใช้อัปโหลดในระดับรูปลักษณ์รวมเท่านั้น ไม่ใช่ภาพเหมือนจริงและไม่ระบุตัวตนจริง
